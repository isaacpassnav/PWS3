## User History
1. Usuario anónimo o invitado, quire registarse.
    - Rellenar formulario
    - 
2. Usuario ya registrado, quiere logearse.
    - Rellenar formulario de logueo.
3. Usuario logeado, quiere reservar turno.
    - Rellenar formulario de reserva.
4. Usuario quiere ver lista de reserva(extra).
    - Realizar filtrado.
5. Usuario logeado, quiere poder cancelar sus turnos.
6. Usuario logeado podra hacer un logout.

## Extra credits
1. Como usuario logeado quiero recibir correo de reserva o cancelacion.
2. Como usuario logueado quiero subir foto en mi perfil.
